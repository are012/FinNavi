# FinNavi — 공시 근거 기반 분석 에이전트

제10회 미래에셋증권 AI 페스티벌 2026 · 공시 Agent(Disclosure Analyst) 과제 · 3인 팀

> 이 저장소는 프로젝트 소개용입니다. 소스코드는 공모전 팀 저장소(비공개)에 있으며, 여기에는 코드를 옮기지 않았습니다.

## 무엇을 만들었나

주최 측이 제공한 **70개 기업의 공시 4,204건**을 근거로 기업 관련 질문에 답하는 API입니다.
HCX-007이 질문의 조건을 해석하고 공시 조회·원문 확인·계산 도구를 고르며, 최종 답변은 수치·인용 검사와 별도의 의미 검토를 거쳐 공시 근거와 함께 반환됩니다.

다루는 질문: 재무 지표와 기업·기간 비교, 시설투자 결정, 자금조달, 계약 정정·해지, 지분변동, 사업·제품·연구개발 내용

## 내 역할

- 공시 데이터 구축과 색인
- 검색·에이전트 구현
- 응답 평가와 검증 기준 보완
- Docker 기반 API의 Naver Cloud 배포

## 처리 흐름

```
질문 → HCX 분석 계획 → 도구 선택 → 공시 조회 · 원문 확인 · 계산
                          ↑__________________|
     → 답변 작성 → 수치 · 인용 검사 → 의미 검토 → API 응답
```

| 항목 | 구현 |
|---|---|
| 분석 모델 | HCX-007 (CLOVA Studio OpenAI 호환 API) |
| API | FastAPI, `GET·POST /answer` |
| 검색·저장 | SQLite FTS5 |
| 사건 관계 | 정정·대체·참조·해지 관계를 테이블과 조회 규칙으로 추적 |
| 계산·검증 | 근거 ID에 연결된 Decimal 계산, 수치 바인딩, 의미 검토 |
| 배포 | Docker Compose, Naver Cloud |

## 풀어낸 문제

**숫자가 맞아도 의미가 틀린 답**

응답이 정상으로 돌아오고 금액도 맞지만, 전환사채 발행을 유상증자로 설명하거나 계약 체결과 후속 해지의 관계를 잘못 해석하는 사례가 있었습니다.
기업·기간·사건 유형·원문 근거를 함께 확인하도록 검증 기준을 보완하고, 근거가 부족하면 "확인 불가"로 구분했습니다. 내용 오류와 호출 오류를 나눠 검토할 수 있게 됐습니다.

**호출 한도와 응답 시한**

문맥과 생성량이 토큰 한도를 넘거나, 탐색에 시간을 써서 답변·검증이 시한 안에 끝나지 않는 문제가 있었습니다.
요청 크기와 단계별 생성 상한을 조정하고 탐색·생성의 시간 예산을 나눴습니다. 기본 예산은 전체 240초·탐색 150초, 최대 4라운드·총 12개 도구 호출입니다. 배포할 때는 이전 설정과 이미지를 보존해 되돌릴 수 있게 했습니다.
